# Campus ID Card Designer

A mobile-first, offline-capable web application for authorized schools, colleges and universities to design institutional student ID cards and export them as high-resolution PNG files.

## Files

- `index.html` — main application
- `style.css` — complete UI and responsive design
- `app.js` — editor, templates, image upload, CSV import, local save and PNG export

## Run

Open `index.html` in a modern browser.

No server, database, CDN, framework or API is required.

## Main features

- Portrait / landscape cards
- Institution and student fields
- Logo, student photo and signature upload
- Drag elements on the card
- Element editor with position, size, text, colors and font settings
- Classic / Modern / Minimal templates
- Add text, shapes, lines and a deterministic visual identification-code element
- Local device save/load
- Dark mode
- PNG export
- Print
- CSV first-row import for quick student data entry
- Responsive mobile UI
